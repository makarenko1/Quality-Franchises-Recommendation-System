Summary

This folder contains preprocessing code for the MovieLens 32M movie metadata, ratings, and tags files. The preprocessing converts the raw MovieLens CSV files into the cleaned CSV format used by this project.

The raw MovieLens 32M files are expected to be placed in a raw directory beside the preprocessing script.

datasets/movies-32M/raw/movies.csv
datasets/movies-32M/raw/ratings.csv
datasets/movies-32M/raw/tags.csv

The movies.csv file is required. The ratings.csv and tags.csv files are optional: if they exist, they are cleaned, validated, and saved; if they do not exist, the script still cleans the movie metadata.

Raw File Structure

Movies File

The raw movies.csv file should contain:

movieId,title,genres

The preprocessing script renames these columns to:

MovieID,Title,Genres

Ratings File

If provided, the raw ratings.csv file should contain:

userId,movieId,rating,timestamp

The preprocessing script renames these columns to:

UserID,MovieID,Rating,Timestamp

Tags File

If provided, the raw tags.csv file should contain:

userId,movieId,tag,timestamp

The preprocessing script renames these columns to:

UserID,MovieID,Tag,Timestamp

Outputs

Running movies_32m_preprocess.py creates the following files:

Output File Description
movies_clean.csv Cleaned movie metadata. Contains MovieID, cleaned Title, extracted Year, and split genre columns such as Genre1, Genre2, etc.
movies_ratings_clean.csv Cleaned ratings, if ratings.csv exists. Contains one rating per UserID, MovieID pair.
movies_tags_clean.csv Cleaned tags, if tags.csv exists.
movies_cleaning_log.txt Text log of all major cleaning steps, dropped rows, and validation checks.

Main Cleaning Steps

  • Load MovieLens 32M CSV files.
  • Rename columns to the project naming convention.
  • Remove null, blank, duplicate, and invalid rows.
  • Convert titles, genres, and tags to ASCII.
  • Extract release year from movie titles.
  • Fix MovieLens-style trailing articles, such as Matrix, The.
  • Remove movies with (no genres listed).
  • Validate genre tokens against a whitelist.
  • Split pipe-separated genres into separate columns.
  • Validate ratings as half-star values in the range 0.5 to 5.0.
  • Remove ratings and tags that reference missing movies.

Usage

From the datasets/movies-32M directory, run:

python movies_32m_preprocess.py

Or import it from another script:

from movies_32m_preprocess import preprocess_movies_32m
movies, ratings, tags = preprocess_movies_32m()

Notes

Unlike the earlier 1M preprocessing script, this MovieLens 32M version does not use hard-coded maximum user or movie IDs. MovieLens 32M has much larger identifiers, so the script only checks that IDs are positive integers.

The script also supports movie-only preprocessing. This is useful when only movies.csv is available.
